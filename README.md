## ⚡ Flagship Systems & Architectures

1. **DNS Shield Platform**: High-throughput DNS threat filtering, DGA family attribution, and real-time TreeSHAP feature attribution.
2. **Privacy-Preserving Federated Learning / SplitFed**: Decentralized multi-hospital chest X-ray diagnosis with cut-layer activations and NoPeek loss.
3. **12-Lead ECG Arrhythmia Classification**: Continuous Wavelet Transform (CWT) scalograms fed into EfficientNet-B4 with Grad-CAM visual heatmaps.
4. **TON-IoT Intrusion Detection**: Two-stage IDS with XGBoost anomaly detection and LightGBM multi-attack classification.
5. **Verdict AI / VeriFake**: Real-time multi-modal fake news detection combining fine-tuned DeBERTa-v3 NLP and Swin Transformer vision.
6. **Ayurveda Intelligence Platform**: Sanskrit medical synonym normalization and hybrid semantic ranking engine.

## 🛠️ Hardware & Embedded IoT Lab

- **Zephyr RTOS on Raspberry Pi Pico 2 (RP2350)**: ARM Cortex-M33 dual-core microcontroller firmware, cooperative multi-threading, sensor networks, and edge anomaly detection.

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/Kshitiz-Khandelwal/Portfolio-webiste.git

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:3000` or `http://localhost:3001` in your browser.
